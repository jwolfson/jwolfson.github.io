# Academic Website (Jekyll) - Julian Wolfson, Ph.D.

This repository contains the Jekyll site source files for Julian Wolfson's personal academic website, structured for direct deployment on GitHub Pages.

## Included Files
- `_config.yml`: Global settings and navigation
- `Gemfile`: Ruby dependencies for local previewing
- `index.md`: Main landing page
- `_pages/`: Research, Teaching, Software, and Service pages
- `README.md`: Setup instructions

## Quick Deployment to GitHub Pages
1. Create a repository on GitHub named `jwolfson.github.io`.
2. Unzip these files and commit them to the repository's `main` branch.
3. Go to **Repository Settings** -> **Pages**.
4. Set source to **Deploy from a branch** (`main` / `/root`).
5. Your site will automatically build and publish!
